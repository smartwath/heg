# Angular Core Rules

- Follow the current Angular project conventions.
- Keep components small and focused.
- Do not put HTML inside TypeScript.
- Use external HTML templates.
- Use external stylesheet files.
- Keep TypeScript focused on state and behavior.
- Avoid large monolithic components.
- Prefer reusable components.
- Avoid duplicated UI logic.
- Prefer Angular signals for local reactive state when appropriate.
- Use @if and @for for new Angular control flow.
- Avoid any unless explicitly justified.
